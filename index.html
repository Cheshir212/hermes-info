Hermes

Hermes — приложение для личного использования, предназначенное для автоматизации задач и работы с данными подключённого аккаунта Google.

Приложение не предоставляет публичную регистрацию и не предназначено для обслуживания сторонних пользователей.

Возможности

  • создавать и проверять зашифрованные резервные копии в Google Drive;
  • работать с файлами, документами и таблицами;
  • выполнять операции с электронной почтой и календарём;
  • читать контакты для выполнения задач.

Действия выполняются по запросу пользователя или по настроенному расписанию. Предоставление разрешений не означает автоматическую обработку всех данных аккаунта.

Управление доступом

Доступ к аккаунту можно отозвать в настройках безопасности Google.
